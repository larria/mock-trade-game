# A股简单 · 交易修行场

面向所有玩家的沪深 300 历史行情盲图模拟交易游戏。隐藏名称与日期，通过逐日决策练习技术分析、仓位管理与交易纪律。

[在线体验](https://larria.github.io/mock-trade-game/) · **v1.0.0**

## 规格文档

- [产品规格](docs/PRODUCT_SPEC.md)：用户流程、交易规则、参数范围、图表、存档、PWA 与验收要求。
- [开发规格](docs/DEVELOPMENT_SPEC.md)：架构、数据契约、指标公式、更新协议、测试与发布。

两份规格只描述当前最新实现。功能调整时直接更新对应章节，不记录版本历史或变更日志。

## 功能

- 每局 7–200 个交易日，默认 30 日；初始资金、历史窗口、佣金费率、滑点和交易单位可配置。
- 日/周/月 K，MA 叠加主图；成交量、MACD、KDJ 独立副图，支持参数、联动十字光标、缩放、全屏与买卖标记。
- 交易理由、进度自动保存、战绩统计、最大回撤、收益基准和 CSV 导出。
- 日间/夜间主题、涨跌配色、默认仓位、交易确认与键盘快捷键。
- PWA 安装、离线应用壳；侧栏底部或手机顶部版本入口检查与点击更新，更新先保存当前进度。

成交采用下一交易日收盘价，并计入设定的佣金和滑点；图表只使用已揭示的训练日。完成后揭晓股票和日期。新抽取行情需要联网；已经保存的对局可离线继续。

## 本地运行

```sh
npm install
npm run dev
```

访问 http://localhost:5173 。PWA 需要 HTTPS 或 localhost，直接打开 HTML 文件时不启用安装与离线缓存。

```sh
npm test
npm run build
```

纯 HTML/CSS/JavaScript，ECharts 本地打包，无应用框架。构建从 package.json 读取版本并生成资源指纹、version.js、sw.js 和 dist/。修改运行资源后须重新构建；已有缓存通过版本入口更新。

## 发布

```sh
git push origin main
npm run deploy
```

发布命令只将 dist/ 运行资源上传 gh-pages；源码和规格文档在 main。公开版本号维护在 package.json，运行资源变化即使不修改公开版本号也能识别更新。

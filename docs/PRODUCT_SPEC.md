# A股简单：产品规格

本文是产品当前行为的唯一产品规格，描述已实现的最新状态。任何产品变更都必须直接修改对应章节，使全文保持一致；不追加变更历史、旧版本行为或待实现方案。

## 1. 产品定位与用户

A股简单是一款面向所有玩家的多市场 A 股历史行情盲图模拟交易游戏。通过隐藏股票名称和真实日期，玩家使用价格走势、技术指标与仓位纪律进行逐日决策，在训练结束后验证策略表现。

适用人群包括希望学习 K 线和仓位管理的初学者，以及希望练习多周期技术分析的交易者。无需注册、登录或真实资金。产品使用统一的公共品牌和中性称呼“交易练习生”，不包含个人署名或专属玩家设定。

游戏以训练和复盘为目标，不连接实盘交易账户。它采用简化的历史收盘成交模型，当前不模拟盘口、涨跌停无法成交、停牌订单排队、税费最低收费、卖空或杠杆。

## 3. 完整训练流程

### 3.1 未开局

工作台展示账户预设和明确标注为“演示行情”的样例图表。玩家可以预先调整指标、K 线周期和训练规则；样例行情不计入战绩。

点击“开始盲图挑战”后，系统从所选的沪深 300、中证 500、全部科创板和创业板标的中合并去重后随机抽取股票，加载新浪加密日 K 数据，解码、校验并前复权。历史不足则尝试其他标的，最多尝试 8 次，每次请求超时为 8 秒。加载过程中展示尝试进度，并允许取消。加载失败后回到工作台并提示重试，不以演示行情替代真实对局。

标的列表为可复核的完整市场快照。沪深 300 和中证 500 使用中证指数官方成分表；科创板和创业板使用新浪完整板块分页名单。每次更新必须通过数量与代码唯一性校验，不能用指数样本替代板块全部上市股票。当前快照日期为 2026-11-05，指数成分表数据日期为 2026-11-04；沪深 300 为 300 只，中证 500 为 500 只，科创板为 618 只，创业板为 1,411 只，四池合并去重后为 2,633 只。

设置中可多选标的范围，默认全部选中，至少选择一个。每只去重后的股票抽取概率相同，不能因属于多个范围而提高权重。页面显示所选股票数量、范围和快照日期；修改范围对新一局生效。历史区间使用当前快照中的股票，不回溯当时指数成员，因此样本存在成分选择和存续偏差。新上市股票若不能容纳历史窗口、训练天数和末端间隔，会在生成对局时跳过。

### 3.2 生成对局

系统保留指定数量的开局前历史 K 线，随机选择连续训练区间，并确保训练末日之后仍有至少 30 个交易日的数据。游戏周期以真实数据中的交易日数量计算，不含周末和休市日。

开局冻结训练规则，包括交易日数、标的范围、初始资金、历史窗口、佣金、滑点和交易单位。起始状态为空仓，现金等于初始资金，进度为 0；图表仅显示开局前已知行情。

股票名称、代码和真实日期在结算前隐藏。图表用 D、W、M 的相对索引代替日期，不显示任何尚未揭示的日线或由这些日线计算的指标。

### 3.3 决策与成交

每次决策包含三个方向之一：买入、卖出、观望。

- 买入比例相对于当前可用现金；卖出比例相对于当前持仓股数。
- 快选支持 1/4、1/3、1/2、全仓或清仓，输入框和滑条支持自定义比例。
- 输入框支持 1%–100%，精度 0.01 个百分点；1/3 快选在内部保存精确分数，输入展示为近似值。
- 玩家可以填写最多 160 字符的交易理由，记录在此次决策中。
- 买入、卖出默认弹出确认框，显示比例和费率；可在设置中关闭。
- 观望直接揭示下一交易日，持仓状态保持不变。
- 每个有效决策以“下一交易日收盘价”作为成交基准，推进一天。参考金额基于当前已知信息估算，不保证具体成交股数。
- 买入手续费占用本次预算，数量向下取整至交易单位；卖出按比例向下取整，全量清仓出售全部剩余股数。
- 资金或股数不足、不合法的指令不成交、不扣费、不消耗交易日。
- 已知没有持仓时禁用卖出；成功清仓后回到可买入状态。

开局尚未决策时可以“重新抽题”，该题不计战绩。产生决策后不能更换标的或跳过余下交易日；导航至战绩、指南或设置不会结束对局。

### 3.4 结算

达到设定交易日数后，自动结束并揭晓股票、代码和真实日期。最后仍有持仓时，以最后收盘价估值，不强制平仓，也不额外收取假定卖出佣金。

展示最终资产、单局收益、买入持有基准、超额收益、买卖次数、最大回撤和累计手续费，自动保存训练档案。买入持有基准是开局前最后收盘至训练末日的价格变动，不扣模拟佣金或滑点。

结算后可以继续切换周期与指标分析完整已结束区间；可以开始新一局或进入复盘战绩。

## 4. 账户和交易成本

| 项目 | 规则 |
| --- | --- |
| 账户总资产 | 可用现金 + 当前股数 × 最新已揭示收盘价 |
| 累计收益 | 当前总资产 / 初始资金 − 1 |
| 仓位 | 持仓市值 / 总资产 |
| 双向佣金 | 按每笔成交金额的设定百分比收取，买卖同一费率 |
| 买入滑点 | 基准收盘价乘以 1 + 滑点百分比 |
| 卖出滑点 | 基准收盘价乘以 1 − 滑点百分比 |
| 持仓成本 | 买入成交金额和买入手续费累加，卖出按平均成本等比例扣减 |
| 最大回撤 | 每日收盘总资产相对历史收盘资产最高值的最大跌幅，含初始资金 |

费率使用百分比单位，例如输入 0.03 表示 0.03%，即万分之三。佣金和滑点各支持 0%–1%，步长为 0.0001 个百分点。没有最低佣金、独立印花税或过户费项目。

## 5. 训练设置

| 设置 | 默认 | 允许值与说明 |
| --- | --- | --- |
| 每局交易日数 | 30 | 整数 7–500，预设 7/14/30/60/100/200/365/500 |
| 标的范围 | 四个范围全部选中 | 沪深300、中证500、科创板、创业板多选；至少一项，合并去重 |
| 初始资金 | 1,000,000 元 | 10,000–100,000,000 元，表单步长 10,000 |
| 开局历史窗口 | 200 根日 K | 120、200、500、1,000、2,000 |
| 双向佣金费率 | 0% | 0%–1%，步长 0.0001 |
| 成交滑点 | 0% | 0%–1%，步长 0.0001 |
| 交易单位 | 整股 | 1 股或 100 股一手 |

进行中修改上述训练规则仅作用于新一局；设置页明确展示当前对局采用的周期和费率。图表与偏好设置保存后即时应用。取消设置丢弃本次编辑；恢复默认只填充表单，仍需保存才能生效。

## 6. 行情分析

### 6.1 K 线周期

日 K 使用原始交易日。周 K 按周一为起点的自然周聚合；月 K 按自然年月聚合。每根聚合 K 线的开盘取首日、收盘取末日、最高最低取区间极值、成交量与成交额求和，不补造休市日。

形成中的最后周 K 或月 K 仅包含截至当前游戏进度的交易日。界面明确说明末根可能仍在形成。切换周期后，所有指标参数按对应周期 K 线根数计算；行情顶部的“日涨跌”仍表示最新日线涨跌。

### 6.2 主图

主图显示蜡烛图和最多 6 条 MA 均线，默认 MA5、MA10、MA20、MA60，支持不重复的整数周期 2–250。MA 属于主图，不能作为独立副图。

可启用持仓成本虚线和 B/S 买卖标记。聚合周期中，标记显示在包含成交日的周期 K 线上。均线完整样本不足时显示“—”，不提前生成值。

### 6.3 副图

| 副图 | 默认状态 | 参数及显示 |
| --- | --- | --- |
| 成交量 VOL | 开启 | 与 K 线颜色联动，默认 VMA5/VMA10，支持最多 2 条 2–250 的不重复整数周期 |
| MACD | 开启 | EMA 快线 12、慢线 26、信号 9；DIF、DEA 和 2×差值柱 |
| KDJ | 关闭 | RSV 周期 9，K/D 平滑各 3；K、D、J 曲线与 20/80 参考线 |

MACD 快线允许 2–100、慢线 3–200、信号 2–100，快线必须小于慢线。KDJ RSV 周期允许 2–100，K/D 平滑允许 1–50。成交量、MACD、KDJ 是独立副图，可以同时开启。

### 6.4 副图底部读数

MACD 副图最底部显示 `MACD(快,慢,信号)` 参数、DIF、DEA、MACD 数值；KDJ 副图底部显示 `KDJ(RSV,K平滑,D平滑)` 参数、K、D、J 数值。各数值使用对应指标颜色。默认三位小数，可统一配置 2–6 位。两种副图的底部读数可分别开关，不影响曲线计算。

默认显示相对前一根同周期 K 线的升降箭头：↑ 增加，↓ 减少，→ 持平。箭头比较原始计算值，四舍五入后的显示值相同仍可能有升降方向。历史不足时显示 —，无可比前值时不显示箭头。可统一关闭箭头。

底栏随主副图十字光标同步到所指 K 线；未指向时显示最后一根，移开后恢复。周/月模式比较前一根周/月 K，不与前一日混比。手机使用两行排布，保留全部读数，与时间刻度、下一副图和缩放条分开。

### 6.5 图表交互

主副图共用时间轴、十字光标和缩放范围。桌面支持滚轮缩放、拖动平移和底部滑块；手机支持触摸操作。图表支持重置缩放和全屏；浏览器不支持全屏时采用页面内全屏布局，Esc 可退出。

鼠标指向 K 线时展示相对日期或结算后的真实日期、OHLC、成交量、周期内交易日数以及开启指标的读数。移开时恢复最后一根的读数。

更早的已知历史行情用于指标预热；它不包含未揭示训练日。默认展示范围为最近 85 根日 K、52 根周 K或 36 根月 K，实际范围不超过已有数据。

## 7. 显示与操作偏好

- 米白日间与松绿夜间主题。
- 红涨绿跌或绿涨红跌，默认采用 A 股习惯。
- 默认下单比例 1/4、1/3、1/2 或全仓，默认 1/4。
- 买卖确认、键盘快捷键和交易手记开关，默认全部开启。
- 快捷键：B 买入、S 卖出、H 观望、Enter 提交、1/2/3 切换日周月 K、逗号打开设置。
- 输入框、文字编辑区、弹窗、加载中或非交易工作台不响应交易快捷键。
- 关键按钮支持键盘焦点，弹窗支持关闭和取消；设置错误定位到对应分类和字段。

## 8. 存档与战绩

设置、当前对局和完成战绩保存在当前浏览器、当前站点的本地存储中。没有账户同步或跨设备共享。首次打开可读取兼容格式的既有存档，后续使用公共应用命名空间写入。

对局生成后和每次有效决策后自动保存。刷新可以恢复训练规则、进度、现金、持仓、指标所需历史行情和决策日志。存储不可用时提示玩家导出备份，不能保证刷新后恢复。

复盘页包含局数、平均单局收益、盈利胜率、最佳单局收益、跑赢基准局数和每局档案。至少两局时增加策略与基准收益对照曲线；这条曲线展示每局独立收益，不是复利账户净值。

CSV 使用 UTF-8 BOM，可供中文表格软件打开。导出字段包括完成时间、股票、代码、区间、周期、期末资产、收益、基准、回撤、手续费和买卖次数。清空全部战绩需要确认，不删除当前对局。当前不提供 CSV 导入或已结束对局完整重放。

## 9. PWA 安装、离线与更新

### 9.1 安装

PWA 名称为“A股简单 · 交易修行场”，短名称为“A股简单”，独立窗口显示；包含普通 192/512 图标、512 maskable 图标和 Apple 主屏幕图标。应用范围和启动地址均相对于部署目录，支持 GitHub Pages 项目子路径。

HTTPS 或 localhost 下启用 Service Worker。浏览器支持安装提示时显示“安装应用”；已安装或提示能力不可用时隐藏该按钮。iOS 用户使用浏览器“添加到主屏幕”菜单。直接打开本地文件可运行普通页面，但不能启用 PWA。

### 9.2 离线

首个版本必须联网完成全部关键资源缓存后才能离线使用。离线可打开工作台、切换图表、查看本地战绩、修改偏好、继续已经保存的对局。新抽取标的仍依赖网络。外部字体不可用时使用系统字体，不影响交易功能。

### 9.3 版本入口

当前公开版本为 **v1.0.0**。入口显示当前页面实际运行的版本，不将尚未应用的更新作为当前版本。桌面显示版本、状态和更新图标；手机以版本和图标组成紧凑按钮，新版本使用强调色和提示点。

| 状态 | 交互 |
| --- | --- |
| 检查更新 | 点击检查，页面加载也会自动检查 |
| 检查中 | 暂停重复点击，检查服务端并等待下载 |
| 已是最新 | 当前资源与可用发布一致，点击可再次检查 |
| 点击更新 | 新发布已完整准备，点击保存进度并应用 |
| 更新中 | 切换资源并刷新，防止重复更新 |
| 离线可用 | 显示离线状态，联网后再次检查 |
| 重试检查 | 检查或下载失败，保留当前可用版本 |
| 更新需 HTTPS | 当前运行环境不支持 PWA |

公开版本号相同但发布内容发生变化时，也能识别并提供更新。发现更新不自动刷新游戏。玩家点击更新后先保存当前对局和决策草稿，再激活新版本和刷新；加载中或弹窗未关闭时要求先完成当前操作。保存失败会阻止切换。

恢复联网会自动检查；页面重新可见且距上次检查超过 15 分钟时检查。另一窗口应用更新后，本窗口显示更新就绪，由本窗口玩家自行点击刷新。

## 10. 交付与验收

上线须满足：公共品牌无个人署名；7/30/200/500 日边界正确；四池名单完整、去重和选择正确；均线主图与三类副图正确；副图底栏参数、数值、方向和联动正确；费率影响成交和收益；指标不使用未来行情；存档能恢复；版本入口能检查和切换；离线应用壳可用；GitHub Pages 子路径安装和资源请求正确；桌面与手机无整体横向溢出。

本规格只记录当前可使用的产品规则。实现、测试或产品规则变化时，开发规格和本文件的相关章节必须同步修改。
